HOW TO UPDATE THE WEDDING WEBSITE

1. Edit the website in VS Code.
2. Save and test the changes with Live Server.
3. When everything looks good, open Terminal in VS Code and run these three commands:

git add .
git commit -m "Update website"
git push

4. Wait a minute or two for GitHub Pages to update.
5. Check https://allorywithanm.com

IMPORTANT:
- Make website changes in VS Code, NOT directly on GitHub.
- Do not run git init again.
- Do not run git remote add origin again.
- Do not change the DNS settings.
